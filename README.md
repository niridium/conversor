# Conversor de Celsius a Fahrenheit

Convertidor web sencillo de temperatura: de grados Celsius (°C) a Fahrenheit (°F).

## Demo

Disponible en **[niridium.github.io/conversor](https://niridium.github.io/conversor)**

## Estructura

```
conversor/
├── index.html    # Estructura principal
├── styles.css    # Estilos
├── script.js     # Lógica de conversión
└── README.md
```

## Cómo usar

1. Abre `index.html` en cualquier navegador, o visita la demo online.
2. Introduce una temperatura en Celsius.
3. Pulsa **Convertir** o pulsa **Enter**.

## Fórmula

```
°F = (°C × 9/5) + 32
```
